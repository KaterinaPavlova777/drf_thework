Инструкция по запуску приложения через Docker
Предварительные требования

Установленный Docker на вашей системе
Установленный Docker Compose
Настроенный файл .env с необходимыми переменными окружения
Запуск приложения

Клонируйте репозиторий (если ещё не сделали):
bash
git clone <ссылка-на-репозиторий>
cd <папка-проекта>
Соберите Docker-контейнеры:
bash
docker-compose build
Запустите сервисы:
bash
docker-compose up
Для запуска в фоновом режиме:
bash
docker-compose up -d
Описание сервисов

Приложение состоит из нескольких сервисов:

Redis - сервер кэширования и брокер сообщений для Celery
Порт: 6379 (внутри сети Docker)
Автоматически перезапускается при ошибках
PostgreSQL - база данных
Порт: 5432 (внутри сети Docker)
Данные сохраняются в volume pg_data
Проверка здоровья: проверяет доступность БД
App - основное приложение (Django)
Порт: 8000 (доступен на localhost:8000)
Автоматически выполняет миграции при запуске
Зависит от работоспособности БД
Celery - воркер для асинхронных задач
Зависит от Redis, БД и основного приложения
Автоматически перезапускается при ошибках
Celery Beat - планировщик периодических задач
Зависит от тех же сервисов, что и Celery
Монтирует текущую директорию в контейнер
